# Project Analysis & Maintenance Rule

## Aturan Utama Bagi Agent:
1. **Analisa Cepat Menggunakan Guide:**
   - Ketika ingin membuat fitur, debug masalah, atau melakukan perubahan pada proyek ini, **cukup analisa file [PROJECT_ANALYSIS_GUIDE.md](file:///Applications/XAMPP/xamppfiles/htdocs/hris_app/PROJECT_ANALYSIS_GUIDE.md)** terlebih dahulu sebagai acuan utama arsitektur, daftar akun, role, model, dan alur bisnis.
   - Hindari melakukan pembacaan seluruh file proyek secara berulang jika informasinya sudah tersedia di guide tersebut.

2. **Wajib Update Guide Pasca Pengerjaan:**
   - **Begitu selesai mengerjakan sesuatu** (menambah fitur, route baru, skema database/model baru, alur approval, atau optimasi UI), **agent WAJIB memperbarui file [PROJECT_ANALYSIS_GUIDE.md](file:///Applications/XAMPP/xamppfiles/htdocs/hris_app/PROJECT_ANALYSIS_GUIDE.md)** agar dokumentasi tetap selalu sinkron dan up-to-date untuk tugas berikutnya.
